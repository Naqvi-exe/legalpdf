How to Properly Redact PDFs for Court Filing

Published October 12, 2025 · 5 min read

Redaction is one of the most misunderstood processes in legal document preparation. Every year, law firms face embarrassing or even damaging consequences because a document they believed was redacted contained hidden text beneath a black box.

The Black Box Illusion

Drawing a black rectangle over text in a PDF editor (or even in Microsoft Word) often just places a shape on top of the text layer. The text is still there. Anyone with a basic PDF text-extraction tool can highlight, copy, and paste the "redacted" text.

This is not true redaction. True redaction requires removing the underlying data permanently.

True vs. Visual Redaction

  • Visual Covering: Placing a shape over the text. (Unsafe for sensitive data).
  • True Redaction: Removing the text object entirely from the PDF structure, or rasterizing the page so it becomes an image.

How to Redact Safely

If you are using browser tools like LegalPDF, understand the limitations. Our redaction tool visually covers the text and strips metadata, making it safer than a simple black box. However, for high-stakes litigation, we always recommend a final verification step:

Verification Step: After redacting, open the new PDF, try to highlight the text underneath the black box, and press Ctrl+C (or Cmd+C) to copy. If you can paste the text elsewhere, it is not fully removed.
