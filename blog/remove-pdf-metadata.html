Removing PDF Metadata Before Sharing Legal Documents

Published October 8, 2025 · 4 min read

When you create or edit a PDF, the software embeds a hidden layer of information known as metadata. This data is not visible on the page, but it travels with the file wherever it goes.

What is inside PDF Metadata?

Depending on the software used, a PDF may contain:

  • The full name of the author (e.g., the lawyer or paralegal who drafted it).
  • The name of the original file before conversion (e.g., Draft_Settlement_Offer_v3.docx).
  • The software used to create it (e.g., Microsoft Word, Adobe Acrobat).
  • Creation and modification dates.

Why is it a risk?

Metadata can unintentionally reveal internal information. For example, sending a document to opposing counsel that still contains the original author's name or the internal file path could compromise your firm's drafting process or reveal the identity of a client contact.
